# Scanner

スマホで書類を連続撮影し、四隅を調整して台形補正し、複数ページを1つのPDFに結合・共有できるPWAです。

## 実装済み

- スマホカメラの連続撮影（撮影後もカメラを閉じない）
- 端末内写真の複数選択
- 複数ページ一覧
- 四隅のドラッグ調整
- 四隅を使った台形（パース）補正
- 自動 / カラー / グレー
- 左右90度回転
- ページ順変更 / 削除
- 複数ページPDF結合
- PDF保存
- Web Share APIによる共有（LINE / メール / Google Drive 等、端末側の対応アプリ）
- PWA / ホーム画面追加
- 192px / 512px アプリアイコン
- GitHub Pages向け `base=/scanner-app/`

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
